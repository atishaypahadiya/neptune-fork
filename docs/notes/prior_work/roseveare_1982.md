## What it means for this repository

Only the later Mercury work touches this book, and `docs/phase2/prior_art.md` already treats it
as unread and claims no novelty over its narrative. For `novelty.md` it bears on one row at
most, the comparison of explanations by evidence, and there only as an unread source that might
contain a qualitative version of the same sorting.

## Needs a browser / library

The whole book: an archive.org loan (account and borrow) or a library. What would have to be
read: the chapters on Le Verrier's 1859 analysis and on Newcomb, and the chapters on each class
of hypothesis, for any table that sets the hypotheses against one another on the same data.
